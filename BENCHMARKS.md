# Benchmarking XcodeGen Compatibility

`scripts/bench_public_xcodegen.sh` runs real-world public XcodeGen specs through
both upstream XcodeGen and `xgr`.

The default candidate set intentionally includes larger active repositories with
public XcodeGen specs:

| Candidate | Repository | Spec |
| --- | --- | --- |
| `provenance` | `Provenance-Emu/Provenance` | `project.yml` |
| `tutanota-mail` | `tutao/tutanota` | `app-ios/mail-project.yml` |
| `tutanota-calendar` | `tutao/tutanota` | `app-ios/calendar-project.yml` |
| `element-ios` | `element-hq/element-ios` | `project.yml` |
| `mapbox-maps-ios` | `mapbox/mapbox-maps-ios` | `project.yml` |
| `kiwix-apple` | `kiwix/kiwix-apple` | `project.yml` |

## Prerequisites

```sh
brew install xcodegen hyperfine
```

`hyperfine` is optional. Without it, run with `--no-bench` to do parity checks
only.

## Run

```sh
scripts/bench_public_xcodegen.sh
scripts/bench_public_xcodegen.sh --only element-ios
scripts/bench_public_xcodegen.sh --only kiwix-apple --runs 10
```

Artifacts are written under `.context/bench/public-xcodegen`:

- `repos/`: shallow public repository checkouts
- `runs/`: one-shot generated projects used for byte comparisons
- `diffs/`: unified `project.pbxproj` diffs and recursive `.xcodeproj` diffs
- `results/`: `hyperfine` JSON timing output

The parity check reports both `project.pbxproj` equality and full `.xcodeproj`
directory equality. Full directory equality is stricter because it includes
schemes, workspace metadata, and user data generated by each tool.

## Local Results

Measured on this checkout with upstream XcodeGen 2.45.4 and `hyperfine --runs 5`:

| Candidate | XcodeGen mean | xgr mean | Speedup | `project.pbxproj` parity |
| --- | ---: | ---: | ---: | --- |
| `element-ios` | 1.304 s | 624.3 ms | 2.09x | byte-for-byte match |
| `kiwix-apple` | 129.2 ms | 43.9 ms | 2.94x | byte-for-byte match |

The remaining candidates did not produce comparable benchmark timings in this
environment:

- `provenance`: upstream XcodeGen rejected a target dependency shape.
- `tutanota-mail`: upstream XcodeGen required a missing generated `build`
  source directory.
- `tutanota-calendar`: upstream XcodeGen required a missing generated
  `build-calendar-app` source directory.
- `mapbox-maps-ios`: upstream generation required a local Xcode/Carthage setup
  that was not available in this environment.

For `element-ios` and `kiwix-apple`, full `.xcodeproj` directory equality
matches byte-for-byte, including schemes and workspace metadata.
